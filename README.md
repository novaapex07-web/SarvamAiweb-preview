# Sable & Circuit — Admin Studio (preview)

This is a **static UI preview** of the multi-page admin studio. It runs on
sample data held in the browser (see `assets/mock-supabase.js`); it is **not**
connected to any database. Sign in with any email and password to look around.

The real application lives in the private repository `SarvamAiweb` and talks to
the live Supabase backend.
